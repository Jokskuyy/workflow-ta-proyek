# Konten Khusus Peran

Subdirektori peran digunakan hanya apabila narasi khusus perlu dipisahkan dari `Tugas_Akhir_Draft.md`. Jangan membuat salinan shared content di sini.

Pemetaan branch yang berlaku:

| Branch | Direktori peran |
|---|---|
| `laporan/iman` | `content/roles/iman/` |
| `laporan/dwikhi` | `content/roles/dwikhi/` |
| `laporan/faiz` | `content/roles/faiz/` |

Konten peran dapat menjelaskan fokus masalah, ruang lingkup, keputusan desain, implementasi, bukti, dan kontribusi terhadap perbaikan UAT. Angka hasil pengujian bersama, identitas responden, dan status produk final tidak boleh ditulis ulang di sini.
